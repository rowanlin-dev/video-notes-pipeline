# 03 · 学科分类与受众适配

> 管：怎么判断一个视频属于哪类、写给谁看，以及分类失败时允许发生什么。
> 什么时候读：改 `classify_profile()`、发现所有视频都走通用模板、或要新增学科桶时。

---

## 1. 两类判断，一次调用

`classify_profile()` 同时返回：

- `subject`：`tech` / `humanities` / `social_philosophy` / `general`
- `audience`：`professional` / `informed` / `beginner`

前者决定**大纲骨架**（`SUBJECT_TEMPLATES`），后者决定**术语密度、铺垫深度与篇幅系数**。
两者都不再由调用方猜测，也不允许硬编码。

---

## 2. 硬规则

1. **分类失败必须可见。** 模型不可用、Key 缺失、请求失败时，退回本地关键词启发式，并打印 `[warn]`。不允许静默返回 `general`。
2. **分类不得依赖 openai SDK。** 只要配置了 OpenAI 兼容端点，就应通过 HTTP 调用；SDK 只是可选加速路径。
3. **分类结果可覆盖。** `--subject` / `--audience` 是人工拍板入口；覆盖后不再调用模型。
4. **分类只影响表达，不影响素材。** 字幕、截帧、时间戳不因分类变化。

---

## 3. 实现

```python
profile = classify_profile(title, desc, subtitle[:800], key, base_url, model)
# => {"subject": "tech", "audience": "informed", "reason": "..."}
```

- 模型提示词要求只返回 JSON，并对受众给出明确定义；
- 超时 60s，失败即启发式兜底；
- `classify_subject()` 保留为兼容封装，内部复用 `classify_profile()`。

### 本地启发式

| 信号 | 判定 |
|:--|:--|
| 标题/简介/字幕含 编程、代码、API、浏览器、并发… | `tech` |
| 含 历史、文学、人物、访谈、传记… | `humanities` |
| 含 社会、心理、哲学、伦理、制度… | `social_philosophy` |
| 都不命中 | `general` |
| 含 入门、零基础、小白、科普… | `beginner` |
| 含 源码、底层、原理、架构、进阶… | `professional` |
| 其他 | `informed` |

启发式只求“不空手”，不追求准确率；有 Key 时应优先用模型。

---

## 4. 受众如何影响产物

| 受众 | 术语处理 | 铺垫 | 篇幅系数 |
|:--|:--|:--|--:|
| `professional` | 直接使用，不解释基础概念 | 省略背景 | 0.8 |
| `informed` | 首次出现解释一句 | 给最小背景 | 1.0 |
| `beginner` | 全部通俗化，配类比 | 逐步展开 | 1.35 |

受众同时写进 prompt 与 brief，模型不能只改字数而沿用同一种讲法。

---

## 5. 已知故障与修复

| 现象 | 根因 | 修复 |
|:--|:--|:--|
| 所有视频都走通用六段 | 端点未安装可选的 `openai` SDK，`classify_subject()` 把 SDK 缺失当成“不能分类”，直接 `return general` | 改为 HTTP 调用；失败时启发式 + 告警 |
| 本地视频永远 general | `run_local_pipeline.py` 把 `--subject general` 写死 | 改为调用 `classify_profile()` 并传入 `--audience` |
| 分类结果与内容不符 | 标题过短、简介缺失 | 允许 `--subject/--audience` 覆盖，并在日志打印依据 |

---

## 6. 边界

- 学科桶只有 4 个，是**骨架选择**而非学术分类；新增第 5 个桶前先确认现有 `general` 确实表达不了。
- 受众判断是启发式概率，不是问卷；同一视频的 professional/informed 边界允许人工覆盖。
- 分类不做持久化缓存；同一视频重跑会重新判断，避免模型升级后仍用旧结论。

---

## 7. 条款来源

| 条款 | 来源 |
|:--|:--|
| 分类失败不许静默 | 2026-11-19 对照实验：端点未装可选的 openai SDK，全部视频被静默归为 general，学科模板从未执行 |
| 受众决定篇幅与讲法 | 用户提出：专业读者理解门槛低可压缩，业余读者需要通俗化与铺垫 |
| 人工可覆盖 | 分类是启发式，必须给人工留拍板入口 |
