# 01 · 流水线契约与阶段边界

> 管：七个阶段各自吃什么、吐什么，哪些目录是硬契约，失败时谁负责兜底。
> 什么时候读：改动任一阶段脚本、加新阶段、排查“上一步没产出导致下一步崩”时。

---

## 1. 阶段表

| # | 阶段 | 入口 | 输入 | 产出 | 失败语义 |
|:--|:--|:--|:--|:--|:--|
| 1 | 下载 + 字幕 | `scripts/extract_frames.py` | BV 号 / 本地视频 | `*.mp4`、`*_subtitles.json/.txt` | 官方字幕缺失/串台 → 本地 ASR 兜底 |
| 2 | 抽帧 + 去重 | 同上 + `scripts/smart_select.py` | 视频、字幕 | `scene/`（或 `fixed/`）、`selected/` | 场景检测 0 帧 → 自适应固定间隔，仍写 `scene/` |
| 3 | 视觉打分 | `scripts/score_frames_concurrent.py --mode score` | `selected/` | `vision_scores.json` | 部分帧失败不中断；全失败才非零退出 |
| 4 | 自动精选 | `auto_select.py` | scores + 主题 | `final/`、`final/_selected.json` | 分数缺失的帧不参与排序 |
| 5 | 图内文字提取 | `score_frames_concurrent.py --mode extract` | `final/` | `vision_extract.json` | 单帧失败保留 `error` 字段，配图仍可用 |
| 6 | 写笔记 | `md_note.py` | 字幕 + 提取结果 + 模板 | `output/*.md`（+ `_brief.md`） | 正文过短/过长 → 告警，不静默交付 |
| 7 | 渲染 + 入库 | `md2pdf.py` / `to_ima.py` | Markdown | PDF / 知识库条目 | PDF 失败不删 Markdown |

## 2. 目录契约

```
runs/<BV>_p<N>/
├── <BV>_p<N>.mp4              下载或复用的视频（已存在则跳过）
├── <BV>_p<N>_subtitles.json   {"body":[{"from","to","content"}]}
├── <BV>_p<N>_subtitles.txt    [MMmSSs] 文本
├── scene/                     场景帧（帧名带时间戳）
├── selected/                  去重后的候选帧（纯编号）
├── final/                     精选帧 + _selected.json
└── output/
    ├── *.md / *.pdf
    ├── images/                精选截图 + Mermaid 渲染出的 SVG
    ├── mermaid/               .mmd 源文件
    ├── _brief.md / _brief.json  Agent 原生模式的写作简报
    └── result.json
```

**硬契约**：

- 下游只认 `scene/`、`selected/`、`final/` 三个目录名。任何“换个目录放帧”的改动都会让 `--from-step` 崩溃。
- 每个分 P 独立目录，禁止多视频共用。
- 路径保持纯英文，避免 ffmpeg 与 Windows 控制台编码问题。

## 3. 三条不可违背的产物规则

1. **永远不裁画面去字幕。** 字幕位置不固定、PPT 是全屏，`crop` 一定连带裁掉正文。正确做法是让截图落在字幕空挡（`--slidegap`），没有空挡就接受遮挡。
2. **图号全篇唯一且连续。** 截图与 Mermaid 图共用一条编号序列，从 1 递增；不允许两类图各自从 1 开始。
3. **时间戳必须指向真实时刻。** 图注时间点来自 `_origin_map.json` 的真实秒数；禁止照抄别的视频的时间表。

## 4. 阶段边界即模块边界

本项目的拆分单位是**阶段**，不是行数：

- 一个阶段只做一件事，失败可以单独重跑（`--from-step N`）；
- 阶段之间只通过目录里的文件交换数据，不共享内存对象；
- 新增能力优先做成“阶段内的模式开关”（如 `--mode scene/fixed`），而不是在 `run_pipeline.py` 里堆分支。

以下情况**不要拆**：只被一个阶段调用、少于 60 行、没有独立失败语义的辅助函数，留在原文件。

## 5. 失败与恢复

| 场景 | 行为 | 恢复方式 |
|:--|:--|:--|
| 视频已存在 | 跳过下载 | 删除文件或 `--redownload` |
| 官方字幕缺失/403/串台 | 自动 ASR 兜底 | 检查 `doctor.py` 的音频链路 |
| 场景检测 0 帧 | 自适应固定间隔写入 `scene/` | 无需人工 |
| 部分帧打分 429 | 全局退避，成功帧照常落盘 | `--from-step 3` 重跑失败帧 |
| 图内文字提取失败 | 简报点名该帧，正文只能按主题使用 | 重跑 `--from-step 5` |
| 正文长度异常 | `[warn]` 提示区间下限/上限 | 换模型或 `--emit-brief` |
