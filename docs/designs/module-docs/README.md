# module-docs · 子系统维护手册

> 管：三块最容易被改坏的子系统，各自的职责、内部约束与改动入口。

---

## 1. `note_subject.py` — 分类与预算

**职责**：判断学科桶与受众，计算篇幅区间。

**不可破坏的约束**

- `compute_note_budget()` 只接受内容与受众变量；不得重新引入时长/帧数/播放量。
- 返回 `(lo, hi)` 元组；调用方不得再假设单一整数。
- 分类失败必须有 `[warn]`，不得静默返回 `general`。
- 无 `openai` 包时必须通过 `requests` 走兼容端点。

**改动检查表**

- [ ] 跑 `python scripts/note_subject.py` 自测；
- [ ] 用四类样本（短/长/静默/多 P）核对区间；
- [ ] 确认 `md_note.py` 的日志、简报、告警三处口径一致。

---

## 2. `md_note.py` — 笔记生成

**职责**：读素材、组织 prompt / 简报、写正文、触发 PDF。

**关键常量**

| 常量 | 作用 |
|:--|:--|
| `_MERMAID_PLACEHOLDER_RULE` | Mermaid 图的编号规则 |
| `_NO_FRAME_NOTE` | 无截图时的脑图要求 |
| `SUBJECT_TEMPLATES` | 学科大纲骨架 |
| `AUDIENCE_LABELS` | 受众的讲法说明 |

**不可破坏的约束**

- `--emit-brief` 必须完全不调用外部 LLM；
- 简报必须包含：学科、受众、篇幅区间、截图清单（含跳转链接）、字幕全文；
- 图号规则只有一条：全篇连续唯一；
- 正文长度告警按区间判断，不再使用“目标 80%”；
- 分段模式下，各段区间之和不低于总区间下限的 80%。

**改动检查表**

- [ ] `python -m py_compile md_note.py`；
- [ ] `--from-step 6` 重生成简报，确认三处数字一致；
- [ ] 用旧 run 目录验证向后兼容（缺 `target_range` 时回退 `target_chars`）。

---

## 3. `scripts/extract_frames.py` — 抽帧与字幕

**职责**：下载/复用视频、获取字幕、场景检测或固定间隔抽帧。

**不可破坏的约束**

- 场景检测 0 帧时，fallback 帧必须写入 `scene/`；
- 禁止 `crop` 去字幕；
- `--slidegap` 只提高场景阈值，不改画面；
- 固定间隔的默认值可调，但回退必须按时长自适应（8–30 秒）。

**改动检查表**

- [ ] 用 5 分钟与 45 分钟样本各跑一次，确认帧数与间隔；
- [ ] 确认 `selected/` 能正常生成，下游 Step 3 不报空目录；
- [ ] 确认 `scene/` 帧名仍带时间戳。

---

## 4. 新增模块的判据

满足以下任一条才拆新文件：

- 有独立的失败语义与重跑入口；
- 被两个以上阶段复用；
- 单文件超过 800 行且职责明显分层。

否则留在原文件，避免为“看起来整洁”制造跨文件跳转。
