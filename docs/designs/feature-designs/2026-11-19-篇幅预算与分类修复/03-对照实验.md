# 2026-11-19 迭代 · 03 对照实验

> 管：这一轮怎么验证“规范是否真的带来差异”，以及新版重跑的结果。
> 状态：✅ 已完成

---

## 1. 问题

同一条视频、同一个模型，**只改变提示词/SOP**，输出会差多少？规范带来的是覆盖度，还是只是更长的模板？

样本：BV13UsH6jE4H P1，6 分 37 秒，官方字幕 145 条、3,496 字。

---

## 2. 实验一：规范 vs 自由发挥

**控制变量**

- 素材：同一次采集（字幕、精选帧、图内文字）；
- 模型：同一模型（DeepSeek-V4.1-Flash）；
- A 路由主会话严格按 `--emit-brief` 的 SPEC 撰写；
- B 路由未接触 SPEC 的子代理撰写，只给字幕与截图清单，禁止读取 skill 目录。

| 指标 | A（按规范） | B（自由发挥） |
|:--|--:|--:|
| 中文正文 | 4,688 字 | 1,750 字 |
| 图 | 11（8 截图 + 3 Mermaid） | 6 截图 |
| 结构 | 6 个固定章节 + 时间范围 | 5 段叙事 |
| 时间戳链接 | 8 | 15 |
| PDF | 15 页 | 7 页 |

**结论**

- A 的覆盖、时间轴、图文对齐、可复现性明显更强，但模板感重、图文切碎；
- B 的观点密度与可读性更好（“广播是事后通知”“问自己这件事做两遍会不会出事”），但漏掉 2/8 张图、时间轴不完整、结构不可控；
- 差距中约 60% 来自规范强制的图表与边界补充，40% 来自模板化叙述的低密度段落。

## 3. 实验二：旧版 vs 新版 skill

| 项 | 旧版逻辑 | v1.6.3 |
|:--|:--|:--|
| 学科/受众 | 静默回落 `general` | `tech / informed`，含理由 |
| 结构 | 通用六段 | 技术桶六段 |
| 篇幅口径 | 目标 29,358、下限 23,486 | 区间 3,400–5,500 |
| 实际正文 | 4,688 字 | 3,423 字 |
| 抽帧 | 13 → 精选 8 | 40 → 精选 12 |
| 图号 | 人工统一 | 14 张连续，无撞号 |
| PDF | 15 页 | 14 页 |
| 全流程耗时 | 约 156 秒 | 270 秒（多 27 帧打分） |

新版把“模板选错”和“篇幅失控”两个根因修掉。抽帧从 13 提升到 40 后，精选 12 帧补上了提交、排队、`ifAvailable`、完成版等此前缺失的状态。

## 4. 公式推演

详见 `engineering-standards/02-笔记篇幅预算.md` §3。关键校准：

- 第一轮常数 20000：90 分钟长课上界 3 万+，正常好笔记会误报 → 改为 12000；
- 只看字幕：静默代码演示把 6,000 字图内信息算成 200 字 → 引入 0.35×图中文字；
- 3 小时与 90 分钟区间接近是刻意设计：长课重复率更高，笔记不应线性膨胀。

---

## 5. 局限

- 样本量为 1，结论只说明“这条视频上的差异”，不是普遍规律；
- 两个实验都使用同一模型，不能说明换模型后的差异；
- 篇幅度量存在三套口径（中文字符 / 非空白字符 / 含代码），本次结论以中文正文字符为主；
- 截图与字幕属于第三方内容，**不随仓库发布**；本文件只保留标题、BV 号、时间点与统计值。

## 6. 复现

```bash
# 同一份素材导出简报（不调用外部文本模型）
python run_pipeline.py BV13UsH6jE4H --pages 1 --emit-brief --no-ima

# 按 _brief.md 的 SPEC 写 note.md 后渲染
python md2pdf.py --input runs/BV13UsH6jE4H_p1/output/note.md
```

A/B 两篇笔记与 PDF 仅保存在本地 `runs/`，已由 `.gitignore` 排除。
