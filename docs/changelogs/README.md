## 归档阈值

- 超过 10 条时，保留最近 10 条，其余按月迁到 `99-历史变更/变更记录-YYYY-MM.md`；
- 归档文件头必须声明“仅作追溯，不作执行依据”；
- 归档后不改历史结论，需要更正时追加“更正说明”。
