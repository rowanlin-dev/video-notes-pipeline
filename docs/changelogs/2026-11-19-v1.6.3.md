# v1.6.3 · 2026-11-19

> 主题：字数预算改为「内容 × 受众」区间制；学科/受众分类在无 openai 环境下也能生效。
> 兼容性：`compute_note_budget()` 返回值由整数改为 `(下限, 上限)`。

---

## 变更

### 1. 字数预算重做

- 移除时长、帧数、评论数、播放量输入；
- 信息量 = 字幕字符数 + 0.35 × 图中文字字符数；
- 展开比 `1.4 / (1 + 信息量/12000)`；受众系数 0.8 / 1.0 / 1.35；
- 返回区间，prompt、简报、告警统一按区间判断；
- 本仓样例：29,358 字目标 → 3,400–5,500 字区间。

`[影响文档] docs/designs/engineering-standards/02-笔记篇幅预算.md / docs/api/README.md / SKILL.md / AGENTS.md / README.md`

### 2. 学科与受众分类

- 新增 `classify_profile()`，同时返回 `subject` 与 `audience`；
- 无 `openai` SDK 时通过 `requests` 调用兼容端点，不再静默返回 `general`；
- 模型不可用时使用本地关键词启发式，并打印 `[warn]`；
- B 站流水线与本地流水线都传入分类结果，去掉 `--subject general` 写死；
- `md_note` 新增 `--audience`。

`[影响文档] docs/designs/engineering-standards/03-学科分类与受众适配.md / docs/api/README.md / SKILL.md / AGENTS.md`

### 3. 产物与抽帧修复

- 图号：截图与 Mermaid 共用一条连续序列；
- 提取失败：`load_frames` 标记 `extract_error`，简报列出失败帧并禁止臆造；
- 抽帧回退：场景检测 0 帧时按 `clamp(duration/40, 8, 30)` 自适应；
- 多 P 预算：取本分 P 时长，不再用整稿时长。

`[影响文档] docs/designs/engineering-standards/01-流水线契约与阶段边界.md / docs/designs/engineering-standards/05-验证与回归.md / SKILL.md / README.md`

### 4. 文档体系

- 新增 `docs/`（入口、设计、规范、模块、API、变更、环境）；
- 根 `.gitignore` 不再整体忽略 `docs/`，改为只忽略个人区、复盘与素材。

## 升级提示

- 外部脚本若解包 `compute_note_budget()` 的整数返回值，需要改为元组；
- 未装 `openai` 的端点无需再安装 SDK，分类与正文都可走 HTTP；
- 若本地 `.env` 从旧模板复制，确认 `AD_*`、`FRAME_TRASH_KEYWORDS` 与新模板一致。

## 已知问题

- 长度告警统计“非空白字符”，与中文字符口径不一致；
- `ifAvailable` 之外的共享锁模式尚无示例；
- 图内文字提取失败暂无自动重试。
